# M1 Instagram Bridge Pilot

Independent Playwright service for an Instagram **test professional account only**. Phase 3 supports text receive, employee-initiated text send, recovery sync, mapping, health, and AI draft-only mode.

All feature flags are off by default. Passwords and 2FA codes are never configured or stored by the service. Run `npm run login` in a visible development/test session to create the persistent browser profile manually.

Media, reactions, typing, hidden/view-once messages, AI auto-send, broadcasts, Messenger, and production M1 Store accounts are explicitly unsupported.
